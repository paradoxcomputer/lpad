libpcsclite.so.1 - third-party library bundled with @paradoxcomputer/lpad-linux-x64
===================================================================================

This package ships a copy of libpcsclite.so.1 from pcsc-lite
(https://pcsclite.apdu.fr/, packaged by Debian as libpcsclite1) beside the lpad
binary. It is redistributed unmodified.

Why it is here: the lpad binary records libpcsclite.so.1 as a DT_NEEDED
dependency because the upstream Logos Execution Zone wallet crate links Keycard
smartcard support unconditionally. lpad never opens a card reader, but the
loader still has to resolve the library, so shipping it keeps
`npm i -g @paradoxcomputer/lpad` working on machines without libpcsclite1
installed.
